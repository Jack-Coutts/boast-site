# boast-site

The website for [boast](https://jack-coutts.github.io/boast-site/), the squash match log for iPhone.

Live at **https://jack-coutts.github.io/boast-site/**

- `index.html` is the home page.
- `support.html` is the user guide. It's the App Store support URL.
- `privacy.html` is the privacy policy. It's the App Store privacy URL.
- `style.css` is shared by all three pages.
- `img/` holds the app screenshots, as 660 × 1434 WebP.

Plain HTML and CSS, with no build step. GitHub Pages serves the `main` branch, so a push to `main` goes live within a minute or two.
